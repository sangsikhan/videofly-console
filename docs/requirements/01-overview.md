# VideoFly SaaS — 서비스 개요

## 1. 서비스 목적

VideoFly SaaS는 영상 인프라 구축 없이도 동영상 호스팅·스트리밍·라이브 방송을 즉시 사용할 수 있도록 제공하는 **B2B/B2D(Business-to-Developer) 동영상 플랫폼**입니다.

**OCI(Oracle Cloud Infrastructure) 위에 자체 구축한 동영상 팜(Video Farm)**을 기반으로 하여, JIT(Just-In-Time) 트랜스코딩 및 패키징 기술로 효율적인 동영상 처리·전송을 제공합니다.

---

## 2. 서비스 비전

> "동영상 인프라를 직접 구축하는 시간을 제품 개발에 쓰세요."

- **빠른 시작**: API 키 발급 후 5분 이내 첫 동영상 재생
- **JIT 처리**: 사전 인코딩 없이 재생 시점에 온디맨드 트랜스코딩 + 패키징
- **비용 효율**: 실제 재생된 콘텐츠만 처리 → 불필요한 인코딩 비용 제거
- **완전 관리형**: 인코딩, CDN, 플레이어, 분석까지 단일 플랫폼 제공
- **조직 관리**: 팀·권한 체계로 안전한 멀티 사용자 운영

---

## 3. 타겟 사용자

| 사용자 유형 | 설명 | 주요 니즈 |
|-------------|------|-----------|
| 개발자 (Developer) | API·SDK를 통해 직접 통합 | REST API, Webhook, SDK |
| 콘텐츠 운영자 | 웹 콘솔에서 동영상 관리 | 업로드, 재생, 통계 |
| 조직 관리자 | 팀·비용·보안 정책 관리 | 사용자 초대, 권한, 청구 |
| 라이브 방송 담당자 | 실시간 방송 운영 | 라이브 설정, 모니터링 |

## 4. 핵심 기술 인프라

### 4.1 동영상 팜 (Data Plane) — OCI 자체 구축

| 구성 요소 | 역할 |
|---------|------|
| **Ingest Service** | 동영상 업로드 수신, OCI Object Storage 저장 |
| **JIT Engine** | JIT 트랜스코딩 + JIT 패키징 통합 처리 |
| **Origin Storage** | OCI Object Storage (원본 + 프로파일 결과) |
| **CDN** | OCI CDN (글로벌 엣지 배포) |
| **Analytics Collector** | Kafka + Flink + ClickHouse 대용량 분석 |

### 4.2 Control Plane — VideoFly API Server

| 구성 요소 | 역할 |
|---------|------|
| **API Server** | REST API, 인증, 조직/사용자 관리 |
| **메타데이터 DB** | OCI MySQL (동영상/조직/사용자 메타데이터) |
| **과금 엔진** | 사용량 집계, Stripe 연동 |
| **웹훅 디스패처** | 이벤트 발생 → 고객 엔드포인트 전달 |

### 4.3 ID 체계

모든 리소스는 **ULID 기반 계층적 ID**로 관리합니다:

```
org_{ulid}                          ← 조직
  └── vid_{ulid}                    ← 동영상
        ├── vpa_{vid}_{prof}        ← 프로파일 에셋 (JIT 결과)
        ├── pbk_{ulid}              ← 재생 엔드포인트
        └── trk_{ulid}             ← 자막/오디오 트랙
  └── liv_{ulid}                    ← 라이브 스트림
  └── usr_{ulid}                    ← 조직 사용자
prof_{slug|ulid}                    ← 인코딩 프로파일 (전역/커스텀)
```

자세한 내용: [ID 체계 문서 →](../architecture/03-id-system.md)

## 6. 서비스 범위 (MVP)

### 6.1 포함 기능

**동영상 관리**
- [x] 동영상 업로드 (Direct Upload, URL 수집)
- [x] JIT 트랜스코딩 + 패키징 (HLS, DASH)
- [x] 프로파일 기반 ABR 스트리밍
- [x] ID 기반 원본·프로파일 관리
- [x] 동영상 재생 (공개 / 서명된 URL)
- [x] 썸네일 자동 생성
- [x] 자막/캡션 업로드

**라이브 스트리밍**
- [x] RTMP/SRT 수신
- [x] 라이브 → VOD 자동 전환

**조직 & 사용자**
- [x] 조직(Organization) 생성 및 관리
- [x] 사용자 초대 및 역할(Role) 지정
- [x] RBAC (역할 기반 접근 제어)
- [x] Free → Paid 플랜 전환

**분석**
- [x] 재생 이벤트 수집 (Kafka)
- [x] 기본 통계 (재생수, 시청 시간, QoE)
- [x] 실시간 모니터링 (Flink)

**API / 웹훅**
- [x] REST API
- [x] 웹훅 이벤트
- [x] API 키 관리

### 6.2 Phase 2 로드맵

- [ ] 커스텀 인코딩 프로파일
- [ ] DRM (Widevine, FairPlay, PlayReady)
- [ ] AI 자동 자막 (한국어 특화 STT)
- [ ] 동영상 클립/편집
- [ ] Simulcast (YouTube, Twitch 동시 송출)
- [ ] 고급 분석 (시청 구간 히트맵, 이탈 분석)
