# VideoFly SaaS — 서비스 개요

## 1. 서비스 목적

VideoFly SaaS는 영상 관련 인프라 구축 없이도 동영상 호스팅·스트리밍·라이브 방송을 즉시 사용할 수 있도록 제공하는 **B2B/B2D(Business-to-Developer) 동영상 플랫폼**입니다.

Mux의 글로벌 동영상 인프라를 기반으로 하여, 국내 서비스 환경에 최적화된 콘솔 UI, 한국어 지원, 국내 과금 체계를 제공합니다.

---

## 2. 서비스 비전

> "동영상 인프라를 직접 구축하는 시간을 제품 개발에 쓰세요."

- **빠른 시작**: API 키 발급 후 5분 이내 첫 동영상 재생
- **무한 확장**: 트래픽 급증 시 별도 인프라 작업 없이 자동 확장
- **품질 보장**: AI 기반 퍼-타이틀 인코딩으로 최적 화질/용량 자동 조정
- **완전 관리형**: 인코딩, CDN, 플레이어, 분석까지 단일 플랫폼 제공

---

## 3. 타겟 사용자

| 사용자 유형 | 설명 | 주요 니즈 |
|-------------|------|-----------|
| 개발자 (Developer) | API·SDK를 통해 직접 통합 | REST API, Webhook, SDK |
| 콘텐츠 운영자 | 웹 콘솔에서 동영상 관리 | 업로드, 재생, 통계 |
| 기업 관리자 | 팀·비용·보안 정책 관리 | 사용자 권한, 청구, 보안 |
| 라이브 방송 담당자 | 실시간 방송 운영 | 라이브 설정, 모니터링 |

## 5. 서비스 범위 (MVP)

### 5.1 포함 기능

- [x] 동영상 업로드 (Direct Upload, URL 수집)
- [x] 자동 인코딩 (HLS Adaptive Bitrate)
- [x] 동영상 재생 (공개 / 서명된 URL)
- [x] 썸네일 자동 생성 및 커스텀
- [x] 자막/캡션 업로드 및 자동 생성
- [x] 라이브 스트리밍 (RTMP/SRT 수신)
- [x] 라이브 → VOD 자동 전환
- [x] 동영상 플레이어 임베드 코드
- [x] 기본 분석 (재생수, 시청 시간)
- [x] API 키 관리
- [x] 웹훅 설정
- [x] 플랜별 사용량 제한 및 청구

### 5.2 Phase 2 기능 (로드맵)

- [ ] DRM 암호화 (Widevine, FairPlay, PlayReady)
- [ ] Simulcast (YouTube, Twitch 동시 송출)
- [ ] 동영상 클립 생성
- [ ] 챕터(목차) 기능
- [ ] 팀/권한 관리
- [ ] AI 자동 자막 (한국어)
- [ ] 실시간 모니터링 대시보드
