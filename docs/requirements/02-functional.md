## 5. 역할 및 권한 관리 (RBAC)

### 5.1 기본 역할 정의

| 역할 | 설명 |
|------|------|
| **Admin** (조직 관리자) | 조직 전체 관리. 청구, 사용자 초대·제거, 모든 설정 |
| **Manager** (매니저) | 콘텐츠 관리 + API 설정. 사용자 관리 불가 |
| **Developer** (개발자) | API 키 사용, 동영상 업로드/관리. 설정 변경 불가 |
| **Viewer** (뷰어) | 통계 및 동영상 목록 조회만 가능 |

## 8. API 및 웹훅

### 8.1 API 키 관리

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| F-API-01 | 조직 범위 API 키 발급 (key_id + secret) | P0 |

| F-API-03 | Secret은 최초 1회만 표시 | P0 |

### 8.2 웹훅 이벤트 목록

```
video.uploaded              원본 파일 OCI 저장 완료
video.transcode.started     JIT 트랜스코딩 시작
video.transcode.completed   특정 프로파일 트랜스코딩 완료
video.transcode.failed      트랜스코딩 실패
video.ready                 기본 프로파일 재생 가능 상태
video.deleted               동영상 삭제

live.created                라이브 스트림 생성
live.started                방송 시작 (인코더 연결)
live.disconnected           연결 끊김
live.ended                  방송 종료
live.recording.ready        녹화 VOD 준비 완료

org.member.invited          멤버 초대
org.member.joined           초대 수락
org.member.removed          멤버 제거
org.plan.changed            플랜 변경
```
