# 페이지: 라이브 스트림 목록 (Live Stream List)

**Route:** `/live`  
**접근 권한:** Read 권한 이상

---

## 1. 페이지 목적

계정에 생성된 모든 라이브 스트림을 관리하는 페이지.  
현재 활성 스트림, 대기 중 스트림, 과거 스트림 이력을 확인한다.

---

## 2. 레이아웃 구성

```
┌──────────────────────────────────────────────────────────┐
│  "라이브 스트림"                    [+ 새 라이브 만들기]  │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  [🔴 활성 스트림 섹션]                                    │
│  현재 방송 중인 스트림 1개                               │
│                                                          │
│  [대기 / 비활성 스트림 목록]                              │
│  필터: [상태 ▼] [날짜 ▼]  검색: 🔍 [이름 검색...]       │
│                                                          │
│  [스트림 목록 테이블]                                     │
│                                                          │
│  페이지네이션                                             │
└──────────────────────────────────────────────────────────┘
```

---

## 3. 활성 스트림 섹션

현재 `active` 상태인 스트림을 상단 강조 영역에 표시:

```
🔴 LIVE  제품 런칭 방송
시청자: 342명   방송 시간: 1:23:45   비트레이트: 3,500kbps

[스튜디오 열기]  [스트림 종료]
```

- 시청자 수, 방송 시간: 10초 주기 갱신
- 스튜디오 열기 → `/live/{id}/studio`
- 스트림 종료 → 확인 모달 후 API 호출

---

## 4. 스트림 목록 테이블

### 컬럼 정의

| 컬럼 | 설명 |
|------|------|
| 이름 | 스트림 이름 (클릭 → 상세) |
| 상태 | `active` / `idle` / `disconnected` 배지 |
| 생성일 | YYYY-MM-DD |
| 마지막 방송 | 최근 방송 시작/종료 시간 |
| 총 방송 횟수 | 누적 방송 횟수 |
| 녹화 수 | 저장된 VOD 수 |
| 작업 | 상세 보기 / 스튜디오 / 삭제 |

### 상태 배지

| 상태 | 배지 | 설명 |
|------|------|------|
| `active` | 🔴 LIVE | 현재 방송 중 |
| `idle` | ⚪ 대기 중 | 스트림 준비됨, 미방송 |
| `disconnected` | 🟡 연결 끊김 | 재연결 대기 (reconnect_window 내) |

---

## 5. 필터 및 검색

| 필터 | 옵션 |
|------|------|
| 상태 | 전체 / 활성 / 대기 / 비활성 |
| 날짜 | 오늘 / 최근 7일 / 최근 30일 / 기간 직접 입력 |
| 검색 | 스트림 이름 기준 |

---

## 6. 녹화 VOD 섹션

각 스트림 행을 확장(펼치기)하면 해당 스트림의 녹화 VOD 목록 표시:

```
▼ 제품 런칭 방송
  ├─ 녹화 #1  2024-03-15 14:00 ~ 15:23 (1시간 23분)  [재생] [동영상으로 이동]
  ├─ 녹화 #2  2024-03-10 10:00 ~ 11:05 (1시간 05분)  [재생] [동영상으로 이동]
  └─ 녹화 #3  2024-03-01 09:00 ~ 09:45 (45분)        [재생] [동영상으로 이동]
```
