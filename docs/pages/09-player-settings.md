# 페이지: 플레이어 설정 (Player Settings)

**Route:** `/settings/player`  
**접근 권한:** Admin 권한

---

## 1. 페이지 목적

VideoFly 임베드 플레이어의 외관(브랜딩), 기본 동작, 보안 정책을 설정하는 페이지.  
설정값은 계정 전체 동영상의 기본값으로 적용되며, 동영상별로 개별 재정의 가능.

---

## 2. 레이아웃 구성

```
┌──────────────────────────────────────────────────────────┐
│  "플레이어 설정"                              [저장하기]  │
├──────────────────────────────────────────────────────────┤

│  [탭] ● 브랜딩  ○ 동작  ○ 보안  ○ 도메인 허용 목록      │
│                                                          │
│  ┌────────────────────────┐  ┌──────────────────────┐   │
│  │   설정 폼              │  │  플레이어 미리보기     │   │
│  │                        │  │                      │   │
│  │   (설정 항목들)        │  │  [실시간 미리보기]    │   │
│  │                        │  │                      │   │
│  └────────────────────────┘  └──────────────────────┘   │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## 3. 탭별 설정 상세

### 탭 1. 브랜딩 (Branding)

#### 로고

| 항목 | 설명 |
|------|------|
| 로고 이미지 업로드 | PNG, SVG, 권장 크기: 200×50px, 최대 1MB |
| 로고 위치 | 좌상단 / 우상단 선택 |
| 로고 링크 URL | 로고 클릭 시 이동할 URL |

#### 컬러 테마

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 기본 색상 | `#0066FF` | 재생 버튼, 진행 바 색상 |
| 배경 색상 | `#000000` | 컨트롤 바 배경 |
| 텍스트 색상 | `#FFFFFF` | 자막, UI 텍스트 |

색상 선택: 컬러 피커 + HEX 코드 직접 입력

#### 미리보기

설정 변경 시 오른쪽 플레이어 미리보기에 실시간 반영.

---

### 탭 2. 동작 (Behavior)

#### 기본 재생 동작

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 자동재생 | 비활성 | 페이지 로드 시 자동 재생 |
| 자동재생 시 음소거 | 활성 | 자동재생 시 음소거 (브라우저 정책) |
| 반복 재생 | 비활성 | 영상 종료 후 반복 |
| 인라인 재생 (iOS) | 활성 | iPhone에서 전체화면 없이 재생 |

#### 컨트롤

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 컨트롤 바 표시 | 활성 | 플레이어 컨트롤 UI 표시 여부 |
| 전체화면 버튼 | 활성 | 전체화면 전환 버튼 |
| 화질 선택 버튼 | 활성 | 수동 화질(해상도) 선택 허용 |
| 재생 속도 조절 | 활성 | 0.5x ~ 2x 속도 조절 |
| Picture-in-Picture | 활성 | PiP 모드 허용 |
| 다운로드 버튼 | 비활성 | MP4 다운로드 버튼 표시 |

#### 자막 기본값

| 설정 | 기본값 |
|------|--------|
| 기본 자막 언어 | 없음 (시청자 브라우저 언어 우선) |
| 자막 자동 표시 | 비활성 |

#### 광고 연동 (Phase 2)

- VAST/VPAID URL 설정
- 광고 건너뛰기 허용 여부

---

### 탭 3. 보안 (Security)

#### 재생 정책 기본값

| 정책 | 설명 |
|------|------|
| ● 공개 (Public) | 새로 업로드하는 동영상의 기본 재생 정책 |
| ○ 서명 필요 (Signed) | 모든 동영상에 서명 URL 요구 |

#### Signed Playback 설정

| 설정 | 기본값 | 설명 |
|------|--------|------|
| JWT 기본 만료 시간 | 3600초 (1시간) | 서명된 URL의 유효 시간 |
| Signing Key 생성 | — | RSA 키 쌍 생성 버튼 |

**Signing Key 발급:**
```
[새 서명 키 생성] 버튼

발급 결과:
  Key ID:      sign_key_abc123
  Private Key: -----BEGIN RSA PRIVATE KEY-----
               (최초 1회만 표시, 반드시 저장하세요)
               -----END RSA PRIVATE KEY-----
               [복사] [다운로드 .pem]
```

---

### 탭 4. 도메인 허용 목록 (Domain Allowlist)

임베드 플레이어가 허용된 도메인에서만 로드되도록 제한.

```
허용 도메인 목록:

  example.com          [삭제]
  app.mysite.co.kr     [삭제]
  *.mycompany.com      [삭제]   ← 와일드카드 지원

  [+ 도메인 추가] ___________________________

  ⚠️  도메인이 비어 있으면 모든 도메인에서 임베드를 허용합니다.
```

**도메인 입력 규칙:**
- `example.com` — 해당 도메인만
- `*.example.com` — 모든 서브도메인
- `localhost` — 개발 환경 허용

## 4. 플레이어 미리보기

설정 화면 우측에 실시간 미리보기 플레이어 표시:

```
┌─────────────────────────────┐
│                             │
│    [🎬 샘플 동영상]          │
│                             │
│  ─────────────────────────  │
│  ▶  0:00          ⚙ ⛶ 🔊   │
│  [로고]                     │
└─────────────────────────────┘
```

- 사전 등록된 샘플 동영상으로 미리보기
- 설정 변경 시 즉시 반영 (저장 전 미리보기 가능)

---

## 5. 저장 처리

[저장하기] 클릭 → `PUT /api/v1/settings/player`  
성공 시 → "설정이 저장되었습니다." 토스트 메시지  
이미 임베드된 플레이어에 반영 시간: 최대 5분 (CDN 캐시)

---

```
┌──────────────────────────────────────────────┐
│ <iframe                                      │
│   src="https://player.videofly.co.kr/abc123" │

│   frameborder="0"                            │
│   allow="autoplay; fullscreen"               │
│   allowfullscreen>                           │
│ </iframe>                                    │
└──────────────────────────────────────────────┘
[코드 복사]
```
