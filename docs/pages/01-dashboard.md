# 페이지: 대시보드 (Dashboard)

**Route:** `/dashboard`  
**접근 권한:** 로그인 필요 (모든 역할)

---

## 1. 페이지 목적

서비스 전반의 사용 현황을 한눈에 파악할 수 있는 홈 화면.  
주요 지표 요약, 최근 활동, 사용량 현황을 제공한다.

---

## 2. 레이아웃 구성

```
┌─────────────────────────────────────────────────────────┐
│  HEADER: VideoFly 로고 | 네비게이션 | 계정 메뉴          │
├──────────────────────────────────────────────────────────┤
│  SIDEBAR: 동영상 / 라이브 / 분석 / 설정 / 청구           │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  [이번 달 요약 카드 4개: 재생수, 시청시간, 저장량, 라이브]│
│                                                          │
│  [사용량 게이지: 플랜 대비 사용률]                       │
│                                                          │
│  [최근 업로드 동영상 5개]    [라이브 스트림 현황]         │
│                                                          │
│  [빠른 시작 가이드 (신규 계정)]                          │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## 3. 구성 요소

### 3.1 요약 카드 (Summary Cards)

| 카드 | 표시 데이터 | API 소스 |
|------|-----------|---------|
| 이번 달 총 재생수 | N회 (전월 대비 ±%) | Mux Data API |
| 이번 달 시청 시간 | N분 / 한도 M분 | Mux Data API |
| 저장 용량 | N GB / 한도 M GB | VideoFly 내부 집계 |
| 라이브 스트림 | 현재 활성 N개 | Mux Live API |

- 카드 클릭 시 해당 상세 페이지로 이동
- 데이터 갱신 주기: 5분 (자동 새로고침)

### 3.2 사용량 게이지 (Usage Gauge)

현재 플랜의 각 항목별 사용률을 프로그레스 바로 표시:

```
재생 시간  [████████░░░░░░░] 8,200분 / 10,000분 (82%)
저장 용량  [████░░░░░░░░░░░] 20GB / 50GB (40%)
라이브     [██░░░░░░░░░░░░░] 2시간 / 10시간 (20%)
```

- 80% 초과 시 → 주황색 경고
- 95% 초과 시 → 빨간색 위험 + 업그레이드 CTA 버튼

### 3.3 최근 동영상 목록

- 최근 업로드 5개 표시
- 컬럼: 썸네일, 제목, 상태, 업로드 일시, 재생수
- "동영상 전체 보기" 링크 → `/videos`

### 3.4 라이브 스트림 현황

- 현재 활성(`active`) 스트림 표시
- 컬럼: 스트림 이름, 상태 배지, 시청자 수, 방송 시간
- 활성 스트림 없을 시 → "라이브 만들기" CTA

### 3.5 빠른 시작 가이드

신규 계정(첫 동영상 미업로드 상태)에만 표시:

```
□ 1단계: 첫 동영상 업로드
□ 2단계: 임베드 코드로 내 사이트에 삽입
□ 3단계: API 키 발급 후 API 연동
□ 4단계: 웹훅 설정
```

각 단계 완료 시 체크 표시 및 완료율 프로그레스 바 표시.

---

## 5. 에러 상태

| 상황 | 처리 |
|------|------|
| API 응답 지연 | 스켈레톤 UI (Skeleton Loader) |
| 데이터 없음 | 빈 상태 일러스트 + 안내 문구 |
| API 오류 | 토스트 에러 메시지 + 새로고침 버튼 |

---

## 6. 관련 페이지 이동

- 동영상 목록 → `/videos`
- 라이브 스트림 → `/live`
- 분석 → `/analytics`
- 플랜 업그레이드 → `/billing`
