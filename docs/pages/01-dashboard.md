# 페이지: 대시보드 (Dashboard)

**Route:** `/dashboard`  
**접근 권한:** 로그인 + 조직 소속 (모든 역할)

---

## 1. 페이지 목적

현재 선택된 **조직(Organization)** 의 서비스 전반 현황을 한눈에 파악하는 홈 화면.  
주요 지표 요약, 사용량 현황, 최근 활동을 제공한다.

---

## 2. 조직 컨텍스트 표시

대시보드 상단에 현재 조직 및 본인 역할 표시:

```
┌──────────────────────────────────────────────────────────────┐
│  🎬 VideoFly   [▼ (주)에이비씨]   동영상  라이브  분석       │
│                                                              │
│  안녕하세요, 홍길동님  ·  역할: Admin  ·  Pro 플랜           │
└──────────────────────────────────────────────────────────────┘
```

## 4. 구성 요소 상세

### 4.1 요약 카드

| 카드 | 표시 데이터 | 소스 |
|------|-----------|------|
| 이번 달 총 재생수 | N회 (전월 ±%) | Analytics API (ClickHouse) |
| 이번 달 시청 시간 | N분 / 한도 M분 | Analytics API |
| 저장 용량 | N GB / 한도 M GB | OCI Storage 집계 |
| 활성 라이브 | 현재 N개 | VideoFly API |

### 4.2 사용량 게이지

```
재생 시간  [████████░░░░░░░] 8,200분 / 10,000분 (82%)   ⚠️
저장 용량  [████░░░░░░░░░░░] 20GB / 50GB (40%)
라이브     [██░░░░░░░░░░░░░] 2시간 / 10시간 (20%)
멤버       [████░░░░░░░░░░░] 4명 / 20명 (20%)
```

- 80~94%: 주황 경고
- 95%+: 빨강 + 업그레이드 CTA

### 4.3 Free 플랜 업그레이드 배너

Free 플랜 계정(또는 사용량 90% 이상)에 표시:

```
┌──────────────────────────────────────────────────────────────┐
│  ⚠️ 이번 달 재생 시간이 82%에 도달했습니다.                 │
│  한도 초과 시 분당 ₩15이 추가 청구됩니다.                   │
│  Pro 플랜으로 업그레이드하면 10배 더 여유롭게 사용하세요.   │
│                               [지금 업그레이드] [닫기]       │
└──────────────────────────────────────────────────────────────┘
```

### 4.4 최근 동영상 목록

최근 업로드 5개 표시:

| 컬럼 | 설명 |
|------|------|
| 썸네일 | OCI CDN 경유 60×34px |
| 제목 | 클릭 → `/videos/{vid_id}` |
| `vid_id` | `vid_01HXYZ...` (말줄임) |
| 상태 | `ready` / `warming_up` / `error` 배지 |
| JIT 캐시 | 프로파일 캐시 상태 요약 (예: 3/4 준비) |
| 업로드 일시 | 상대 시간 (예: "3시간 전") |

### 4.5 JIT 처리 현황 (Admin/Manager)

현재 JIT 엔진 부하 및 큐 상황:

```
JIT 처리 현황
  처리 중: 3개   대기: 7개   완료(오늘): 124개
  평균 처리 시간: 2.3초/분 (원본 기준)

최근 JIT 오류:
  ⚠️ vid_01HXYZABC — 480p 프로파일 생성 실패  [재시도]
```

### 4.6 빠른 시작 가이드

신규 계정(첫 동영상 미업로드 상태)에만 표시:

```
VideoFly 시작하기

□ 1단계: 동영상 업로드하기         → [업로드]
□ 2단계: 임베드 코드로 내 사이트에 추가 → [코드 복사]
□ 3단계: API 키 발급                → [설정]
□ 4단계: 웹훅 설정                 → [설정]

진행률: ░░░░░░░░░░ 0/4
```
