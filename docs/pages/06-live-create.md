# 페이지: 라이브 스트림 생성 (Live Create)

**Route:** `/live/new`  
**접근 권한:** Write 권한 이상

---

## 1. 페이지 목적

새로운 라이브 스트림을 생성하고, RTMP/SRT 수신 정보를 발급하는 페이지.  
생성 완료 후 스트림 연결 정보(스트림 키, 인제스트 URL)를 제공한다.

---

## 2. 레이아웃 구성

```
┌──────────────────────────────────────────────────────────┐
│  ← 라이브 목록   /   새 라이브 스트림 만들기              │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  ① 기본 정보                                             │
│     스트림 이름 *: [___________________________]         │
│     설명        : [___________________________]          │
│                                                          │
│  ② 스트림 설정                                           │
│     수신 방식: ● RTMP  ○ SRT                             │
│     재생 정책: ● 공개  ○ 서명 필요                        │
│     자동 녹화: ● 활성  ○ 비활성                           │
│                                                          │
│  ③ 고급 설정 [펼치기 ▼]                                  │
│     재연결 허용 시간: [60] 초                             │
│     최대 비트레이트: [무제한 ▼]                           │
│                                                          │
│  [취소]                     [라이브 스트림 만들기]        │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

---

## 3. 입력 필드 상세

### ① 기본 정보

| 필드 | 타입 | 필수 | 제한 |
|------|------|------|------|
| 스트림 이름 | text | 필수 | 최대 255자 |
| 설명 | textarea | 선택 | 최대 2,000자 |

---

### ② 스트림 설정

#### 수신 방식

| 방식 | 설명 | 포트 | 권장 상황 |
|------|------|------|----------|
| RTMP | 가장 넓은 소프트웨어 호환 | 1935 | OBS, vMix, Wirecast 등 |
| SRT | 저지연, 패킷 손실 복원 | 9000 | 불안정 네트워크, 4K |

#### 재생 정책

| 정책 | 설명 |
|------|------|
| 공개 (public) | 인터넷 누구나 시청 가능 |
| 서명 필요 (signed) | JWT 토큰이 있어야 시청 가능 |

#### 자동 녹화

- 활성: 방송 종료 시 자동으로 VOD 에셋 생성
- 비활성: 녹화 없음

---

### ③ 고급 설정

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 재연결 허용 시간 (reconnect_window) | 60초 | 연결 끊김 후 재연결을 허용하는 시간 창 |
| 최대 지연 시간 | 보통 (~5초) | 저지연/보통 선택 |

---

  rtmp://global-live.mux.com/app
  [복사]

  ****-****-****-**** (보안상 마스킹)

  https://stream.mux.com/{PLAYBACK_ID}.m3u8
  [복사]

HLS 임베드:
  [임베드 코드 보기]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

③ 이 창을 닫고 스튜디오에서 방송 상태를 확인하세요.

## 5. 검증 규칙

| 규칙 | 처리 |
|------|------|
| 스트림 이름 미입력 | 제출 시 인라인 오류 |
| 플랜 라이브 스트림 한도 초과 | 제출 시 "플랜 업그레이드 필요" 안내 |

---

## 6. OBS 설정 안내

생성 완료 화면에 OBS 설정 방법 안내 (Accordion):

```
[OBS 설정 방법 ▼]

1. OBS 실행 → 설정 → 방송
2. 서비스: 사용자 지정
3. 서버: rtmp://global-live.mux.com/app
4. 스트림 키: (위의 스트림 키 입력)
5. 적용 → 확인 후 방송 시작
```
