## 1. 페이지 목적

개발자·운영자가 원하는 문서를 빠르게 찾고 시작할 수 있는 문서 허브.  
무료 계정 전환 CTA를 자연스럽게 포함한다.

## 6. 인기 가이드 섹션

```
인기 가이드

→  ⚡ 5분 빠른 시작 가이드
   첫 번째 동영상을 업로드하고 재생하는 방법

→  🎬 Direct Upload 구현하기
   서버를 거치지 않고 클라이언트에서 직접 업로드

→  🔐 Signed URL로 보안 재생 구현하기
   JWT 토큰 기반 접근 제어 설정

→  📡 라이브 스트리밍 시작하기
   RTMP 수신 → HLS 출력 → VOD 저장

→  🔔 웹훅으로 이벤트 처리하기
   인코딩 완료, 라이브 시작 등 이벤트 수신
```

## 8. 문서 검색 (CMD+K)

- 단축키 `CMD+K` (Mac) / `Ctrl+K` (Windows)로 검색 모달 호출
- 전체 문서 전문 검색 (제목, 본문, 코드)
- 최근 검색어 표시
- 결과: 섹션 단위, 해당 문서로 이동
