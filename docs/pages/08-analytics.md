# 페이지: 분석 / 통계 (Analytics)

**Route:** `/analytics`  
**접근 권한:** Read 권한 이상

---

## 1. 페이지 목적

동영상 재생 품질(QoE), 시청자 행동, 라이브 스트리밍 성과 등  
서비스 전반의 분석 데이터를 시각화하여 콘텐츠 운영 의사결정을 지원한다.

---

## 2. 레이아웃 구성

```
┌──────────────────────────────────────────────────────────┐
│  "분석"                                                  │
│  기간: [오늘] [7일] [30일] [직접입력 ▼]   [CSV 내보내기] │
│  [탭] ● 전체 개요  ○ 동영상별  ○ 라이브별  ○ 품질 모니터 │
├──────────────────────────────────────────────────────────┤
│  [탭 콘텐츠 영역]                                        │
└──────────────────────────────────────────────────────────┘
```

## 3. 탭별 상세 내용

### 탭 1. 전체 개요 (Overview)

#### 요약 카드 (기간 내 합계)

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ 총 재생수    │  │ 순 시청자수   │  │ 총 시청 시간  │  │ 완료율       │
│ 48,200 회   │  │ 31,500 명    │  │ 16,200 분    │  │ 72%          │
│ ▲ +12% 전기간│  │ ▲ +8%        │  │ ▲ +15%       │  │ ▼ -2%        │
└──────────────┘  └──────────────┘  └──────────────┘  └──────────────┘
```

#### 재생수 추이 (라인 차트)

- X축: 날짜 (선택 기간)
- Y축: 재생수
- 전기간 대비 비교 선 (점선)

#### 시청 시간 추이 (라인 차트)

- X축: 날짜
- Y축: 분(min) 단위

### 탭 3. 라이브별 분석 (Live Analytics)

#### 라이브 스트림 선택

```
스트림 선택: [제품 런칭 방송 2024-03-15 ▼]
```

#### 라이브 방송 지표

| 지표 | 값 |
|------|---|
| 방송 시간 | 1시간 23분 |
| 최고 동시 시청자 | 521명 |
| 총 시청 시작 | 1,203회 |
| 평균 시청 시간 | 12분 30초 |

**동시 시청자 타임라인 (Area 차트)**

```
시청자
 600│         ╭──╮
 400│      ╭──╯  ╰──╮
 200│  ╭───╯        ╰───────────
   0└──────────────────────────→ 시간
    14:00  14:30  15:00  15:23
```

**입력 스트림 품질 타임라인**

- 비트레이트(kbps) 추이
- FPS 추이
- 연결 끊김 이벤트 마커

### 탭 4. 품질 모니터링 (Quality Monitor)

실시간 업데이트 (20초 갱신) — 현재 활성 스트림/재생 상태를 실시간 모니터링.

#### 실시간 지표 (전체 계정)

| 지표 | 현재값 | 1시간 전 |
|------|--------|---------|
| 활성 재생 수 | 342 | 280 |
| 오류율 | 0.08% | 0.05% |
| 평균 시작 시간 | 0.9초 | 1.1초 |
| 리버퍼링 비율 | 0.4% | 0.3% |

#### 이상 감지 (Anomaly Detection)

```
⚠️  경고: 모바일 - Android 기기의 오류율이 급등했습니다.
     현재: 2.3%  (평균 대비 +1,800%)
     영향 시청자: 약 45명
     [상세 분석 보기]
```

#### 세그먼트 분석 (다차원 필터)

| 필터 | 옵션 |
|------|------|
| 기기 유형 | 데스크톱 / 모바일 / 태블릿 |
| OS | iOS / Android / Windows / macOS |
| 브라우저 | Chrome / Safari / Firefox / Edge |
| 플레이어 | Mux Player / 직접 구현 |
| CDN 지역 | 아시아 / 북미 / 유럽 |
| 동영상 | 특정 에셋 선택 |
