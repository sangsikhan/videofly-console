### ② VOD (동영상 관리)

**앵커:** `#vod`

```
┌─────────────────────────┐   동영상 업로드부터 재생까지
│                         │
│  [업로드 화면 스크린샷] │   드래그 앤 드롭 또는 URL로 업로드.
│                         │   Mux AI가 콘텐츠를 분석해 최적 인코딩을
│                         │   자동으로 결정합니다.
└─────────────────────────┘
```

**핵심 포인트 (체크리스트 스타일):**

- ✅ **Direct Upload** — 서버 없이 클라이언트에서 직접 Mux로 업로드
- ✅ **URL 수집** — S3, GCS, 외부 URL에서 자동 수집
- ✅ **AI 퍼-타이틀 인코딩** — 콘텐츠별 최적 비트레이트 자동 결정
- ✅ **HLS ABR** — 시청자 네트워크 속도에 따른 화질 자동 조정
- ✅ **4K 지원** — 최대 2160p 해상도
- ✅ **자막 업로드** — VTT, SRT 파일 지원 (20+ 언어)
- ✅ **AI 자동 자막** — 음성 인식으로 자동 생성 (Pro 이상)
- ✅ **썸네일 커스터마이즈** — 시점 지정 캡처 또는 이미지 업로드
- ✅ **클립 생성** — 시작/종료 지점 지정으로 새 에셋 생성

### ③ 라이브 스트리밍

**앵커:** `#live`

```
방송 시작까지 1분

OBS에 RTMP URL과 스트림 키를 입력하면
전 세계로 방송이 즉시 시작됩니다.
```

```
┌─────────────────────────┐
│  [라이브 스튜디오        │   라이브 스트리밍 주요 기능:
│   스크린샷]             │
│                         │   📡 RTMP / SRT 수신
│   🔴 LIVE  01:23:45     │   📺 HLS 출력 (글로벌 CDN)
│   시청자: 342명         │   ⏱️ 지연 3~5초 (표준) / < 1초 (LL-HLS)
└─────────────────────────┘   🎬 방송 종료 후 자동 VOD 저장
                              📡 Simulcast (YouTube, Facebook 동시 송출)
```

**핵심 포인트:**

- ✅ **RTMP / SRT 수신** — OBS, vMix, Wirecast 등 모든 방송 소프트웨어 호환
- ✅ **자동 VOD 저장** — 방송 종료 직후 즉시 다시보기 가능
- ✅ **저지연 (LL-HLS)** — 1초 미만 지연 (인터랙티브 방송)
- ✅ **실시간 시청자 모니터링** — 콘솔에서 시청자 수·품질 실시간 확인
- ✅ **스트림 키 보안** — 마스킹·재발급 지원
- ✅ **Simulcast** — YouTube·Facebook·Twitch 동시 송출 (Pro 이상)

### ⑤ 보안 & 접근 제어

**앵커:** `#security`

```
콘텐츠를 허가된 사람만 볼 수 있게

서명된 URL로 재생 기간·도메인을 제한하고
DRM으로 고가치 콘텐츠를 완벽하게 보호하세요.
```

**핵심 포인트:**

- ✅ **Signed Playback URL** — JWT 서명, 만료 시간 설정
- ✅ **도메인 허용 목록** — 특정 도메인에서만 재생 허용
- ✅ **재생 정책 전환** — 동영상별 공개/비공개 즉시 변경
- ✅ **DRM** — Widevine, FairPlay, PlayReady (Enterprise)

```javascript
// 서버에서 서명된 재생 URL 생성 예시
const token = jwt.sign(
  { sub: playbackId, aud: 'v', exp: now + 3600 },
  signingKey, { algorithm: 'RS256' }
);
const url = `https://stream.mux.com/${playbackId}.m3u8?token=${token}`;
```

### ⑦ API & 개발자 도구

**앵커:** `#api`

```
개발자 친화적 API로 5분 만에 통합

완전한 REST API, 웹훅, 다중 SDK로
기존 서비스에 동영상 기능을 쉽게 추가하세요.
```

```bash
# 동영상 업로드 URL 발급 예시
curl -X POST https://api.videofly.co.kr/v1/videos/upload-url \
  -u KEY_ID:SECRET_KEY \
  -H "Content-Type: application/json" \
  -d '{"title": "제품 데모", "playback_policy": "public"}'
```

**SDK 지원:**

```
Node.js  Python  Go  Ruby
React  Vue  iOS  Android
```

**웹훅으로 실시간 이벤트 처리:**

```javascript
// 인코딩 완료 시 자동 알림
app.post('/webhook', (req, res) => {
  if (req.body.type === 'video.asset.ready') {
    const { id, playback_ids } = req.body.data;
    updateDatabase(id, playback_ids[0].id);
  }
  res.json({ received: true });
});
```
