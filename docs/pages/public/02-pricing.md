**Route:** `/pricing`

---

## 1. 페이지 목적

방문자가 플랜을 비교하고 가입 결정을 내리는 전환 페이지.  
**핵심 원칙:** Free 플랜의 진입 장벽을 최소화하고, 유료 플랜의 가치를 명확히 전달한다.

## 7. FAQ (요금제 전용)

| 질문 | 답변 |
|------|------|
| Free 플랜은 정말 무료인가요? | 네, 신용카드 없이 영구 무료. 한도 내에서 계속 사용 가능합니다. |
| 14일 무료 체험 후 자동 결제되나요? | 아니요. 체험 종료 후 카드를 등록하지 않으면 Free 플랜으로 자동 전환됩니다. |
| 언제든 해지할 수 있나요? | 네, 위약금 없이 언제든지 해지 가능합니다. |
| 연간 결제 후 중도 해지 시 환불되나요? | 잔여 개월 수에 비례하여 환불 처리됩니다. |
| 결제 수단은 무엇을 지원하나요? | 신용카드 (Visa, Mastercard, 국내 카드). Enterprise는 계좌이체 가능. |
| 초과 요금은 어떻게 청구되나요? | 다음 달 정기 청구서에 합산 청구됩니다. |
| 플랜 중간에 업그레이드하면 어떻게 되나요? | 즉시 적용되며, 남은 기간은 일할 계산됩니다. |
