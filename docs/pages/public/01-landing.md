## 7. 기능 상세 (Zigzag Layout)

### Block 1: 동영상 업로드 & 인코딩

```
[콘솔 업로드 화면 GIF]     AI 인코딩으로 최적 화질 자동 결정
                           드래그 앤 드롭으로 업로드,
                           인코딩은 VideoFly가 자동으로 처리합니다.
                           4K · HDR · HLS ABR 지원
```

### Block 2: 플레이어 & 임베드

```
브랜드 색상, 로고 커스터마이즈   [플레이어 커스터마이즈 화면]
iframe 한 줄로 어디든 삽입
React, Vue, iOS, Android SDK 제공
```

### Block 3: 라이브 스트리밍

```
[라이브 스튜디오 화면]   OBS 연결 → 1분 만에 방송 시작
                         방송 종료 후 자동 VOD 저장
                         저지연 (3~5초) · LL-HLS 지원
```

### Block 4: 분석 & 모니터링

```
누가, 어디서, 얼마나 시청했는지   [분석 대시보드 차트]
재생 품질 실시간 모니터링
CSV 내보내기 · API로 원본 데이터 접근
```

## 10. FAQ (Accordion)

| 질문 | 답변 요약 |
|------|----------|
| 무료 플랜은 영구적으로 무료인가요? | 네, 한도 내에서 카드 없이 영구 사용 가능 |
| 한도를 초과하면 어떻게 되나요? | 초과 사용 또는 플랜 업그레이드 선택 가능 |
| API로 직접 연동할 수 있나요? | 네, REST API + 다중 SDK 제공 |
| 직접 인코딩 서버가 필요한가요? | 아니요, 모두 VideoFly가 처리합니다 |
| 동영상은 어디에 저장되나요? | Mux 글로벌 CDN (한국 포함) |
| 계약/약정 기간이 있나요? | 없습니다. 언제든 해지 가능 |
| 라이브 스트리밍은 어떤 소프트웨어와 호환되나요? | OBS, vMix, Wirecast, RTMP 지원 모든 소프트웨어 |
