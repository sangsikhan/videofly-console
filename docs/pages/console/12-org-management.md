# 페이지: 조직 관리 (Organization Management)

**Route:** `/settings/organization`  
**접근 권한:** Admin 역할

---

## 1. 페이지 목적

조직(Organization)의 기본 정보 관리, 조직 간 전환, 새 조직 생성을 처리하는 페이지.

---

## 2. 조직 컨텍스트 전환 (Global Header)

모든 콘솔 페이지 상단 헤더에 **조직 컨텍스트 스위처** 상시 표시:

```
┌──────────────────────────────────────────────────────────────┐
│  🎬 VideoFly  │  [▼ (주)에이비씨 org_XXX]  │ 동영상  라이브 │
│               │                            │              │
│               │  소속 조직 목록:            │              │
│               │  ● (주)에이비씨  (현재)     │              │
│               │    개발팀 스타트업                          │
│               │  ─────────────────                         │
│               │  [+ 새 조직 만들기]                         │
│               │  [조직 초대 수락 보기 (2)]                  │
└──────────────────────────────────────────────────────────────┘
```

- 조직 전환 시 현재 페이지 맥락 초기화 후 대시보드로 이동
- 미처리 초대 수 배지 표시

## 4. 도메인 탭

```
허용된 이메일 도메인 (자동 가입)

특정 도메인 이메일 사용자가 초대 없이 자동으로
이 조직에 합류할 수 있도록 설정합니다.

등록된 도메인:
  abc-company.com     기본 역할: Developer   [삭제]

[+ 도메인 추가]
  도메인: [________________]
  신규 가입자 기본 역할: [Developer ▼]
  [추가]

⚠️ 도메인 소유권 확인이 필요합니다.
   DNS TXT 레코드를 추가해주세요:
   _videofly-verify.abc-company.com  →  "vf-verify-abc123"
```

## 5. 위험 구역 (Danger Zone) 탭

```
⚠️ 위험 구역 — 되돌릴 수 없는 작업입니다

──────────────────────────────────────────────
이 조직에서 나가기
  조직을 떠납니다. 소속 리소스는 유지됩니다.
  마지막 Admin인 경우 다른 Admin 지정 후 가능합니다.
                                    [조직 나가기]

──────────────────────────────────────────────
조직 삭제
  모든 동영상, 라이브 스트림, API 키, 통계 데이터가
  영구 삭제됩니다. 복구 불가능합니다.
                                    [조직 삭제]
```

**조직 삭제 확인 모달:**

```
이 조직을 삭제하려면 조직명을 입력해주세요.

조직명: [(주)에이비씨]
입력: [________________________]

삭제될 항목:
  동영상 1,234개
  라이브 스트림 12개
  API 키 5개
  모든 통계 데이터

[취소]                        [영구 삭제]  ← 입력 일치 시만 활성
```
