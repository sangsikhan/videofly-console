# 페이지: 사용자 관리 (User Management)

**Route:** `/settings/members`  
**접근 권한:** Admin 역할 (조회: Manager 이상)

---

## 1. 페이지 목적

조직 내 멤버를 초대·관리하고, 각 멤버의 역할을 설정하는 페이지.

---

## 2. 레이아웃 구성

```
┌──────────────────────────────────────────────────────────────┐
│  "멤버 관리"                              [+ 멤버 초대]      │
│  (주)에이비씨 · Pro 플랜 · 4/20명 사용   [플랜: 20명까지]   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  검색: 🔍 [이름 또는 이메일...]    필터: [역할 ▼] [상태 ▼]  │
│                                                              │
│  [멤버 목록 테이블]                                          │
│                                                              │
│  [대기 중 초대 섹션]                                         │
└──────────────────────────────────────────────────────────────┘
```

---

## 3. 멤버 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 아바타 + 이름 | 프로필 이미지, 이름 (클릭 → 상세) |
| 이메일 | 계정 이메일 |
| 역할 | 배지 (Admin/Manager/Developer/Viewer) |
| 가입일 | 초대 수락 일시 |
| 마지막 활동 | 마지막 로그인 또는 API 호출 |
| 작업 | 역할 변경, 제거 |

```
┌────────────────────────────────────────────────────────────┐
│  [👤] 홍길동             admin@abc.co.kr   🔴 Admin        │
│       2024-01-15 가입    2024-03-15 활동                   │
│                                          [역할변경] [제거]  │
├────────────────────────────────────────────────────────────┤
│  [👤] 김개발             dev@abc.co.kr    🟢 Developer     │
│       2024-02-01 가입    2024-03-14 활동                   │
│                                          [역할변경] [제거]  │
├────────────────────────────────────────────────────────────┤
│  [👤] 이뷰어             viewer@abc.co.kr ⚪ Viewer        │
│       2024-03-01 가입    2024-03-10 활동                   │
│                                          [역할변경] [제거]  │
└────────────────────────────────────────────────────────────┘
```

**역할 배지 색상:**

| 역할 | 색상 |
|------|------|
| Admin | 🔴 빨강 |
| Manager | 🟠 주황 |
| Developer | 🟢 초록 |
| Viewer | ⚪ 회색 |

---

## 4. 멤버 초대

[+ 멤버 초대] → 슬라이드 패널:

```
멤버 초대

이메일 주소 *
[____________________________________]
(여러 명: 쉼표로 구분 가능)
예: a@example.com, b@example.com

역할 *
  ○ Admin    — 조직 전체 관리 (청구, 사용자, 모든 설정)
  ● Manager  — 콘텐츠 및 API 관리 (사용자 관리 불가)
  ○ Developer — API 사용, 동영상 업로드·관리
  ○ Viewer   — 통계 및 조회만

메시지 (선택)
[____________________________________]
초대 이메일에 포함될 메시지입니다.

초대 링크 유효 기간: 7일

[취소]                        [초대 보내기]
```

**초대 이메일 내용:**

```
제목: [VideoFly] (주)에이비씨에 초대되었습니다

안녕하세요!

홍길동님이 VideoFly의 (주)에이비씨 조직에
Developer 역할로 초대했습니다.

[초대 수락하기]
(링크 유효 기간: 7일)

VideoFly는 동영상 호스팅·스트리밍 플랫폼입니다.
계정이 없으시면 초대 수락 시 자동으로 생성됩니다.
```

## 5. 대기 중 초대 섹션

전송됐으나 아직 수락되지 않은 초대:

```
대기 중 초대 (2건)

┌───────────────────────────────────────────────────────────┐
│  pending@example.com     역할: Manager    만료: 3일 후    │
│                                    [재발송]  [취소]        │
├───────────────────────────────────────────────────────────┤
│  new@example.com         역할: Developer  만료: 6일 후    │
│                                    [재발송]  [취소]        │
└───────────────────────────────────────────────────────────┘
```

---

## 6. 역할 변경 모달

```
역할 변경: 김개발

현재 역할: Developer

새 역할:
  ○ Admin
  ○ Manager
  ● Developer (현재)
  ○ Viewer

[취소]        [변경]
```

**제한 규칙:**
- 마지막 Admin의 역할은 변경 불가 (Admin 최소 1명 유지)
- 자기 자신의 역할 변경 불가 (다른 Admin이 변경)

## 7. 멤버 제거 확인

```

이 사용자가 보유한 API 키는 즉시 비활성화됩니다.

[취소]    [제거]
```

## 8. 플랜 멤버 한도 초과 처리

멤버 수가 플랜 한도에 도달 시:

```
⚠️ 멤버 한도에 도달했습니다

현재 플랜(Starter)은 최대 5명까지 지원합니다.
더 많은 멤버를 초대하려면 플랜을 업그레이드하세요.

Pro 플랜: 최대 20명
Enterprise: 무제한

[플랜 업그레이드]    [닫기]
```
