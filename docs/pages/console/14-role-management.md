# 페이지: 역할 및 권한 관리 (Role & Permission)

**Route:** `/settings/roles`  
**접근 권한:** Admin 역할

---

## 1. 페이지 목적

조직 내 역할(Role)별 권한 현황을 확인하고, 커스텀 역할을 관리하는 페이지.  
MVP에서는 기본 4개 역할의 권한 현황 조회 및 역할별 멤버 현황을 제공한다.

## 4. 역할별 권한 상세 설명

### 🔴 Admin (조직 관리자)

```
포함 권한 (전체):
  ✅ 모든 동영상 생성·편집·삭제
  ✅ 모든 라이브 스트림 관리
  ✅ 플레이어 설정 변경
  ✅ API 키 발급 및 삭제
  ✅ 웹훅 관리
  ✅ 사용자 초대·역할 변경·제거
  ✅ 조직 정보 수정
  ✅ 플랜 변경 및 청구 관리
  ✅ 통계 및 CSV 내보내기

주의:
  - 조직당 Admin은 최소 1명 이상 유지해야 합니다
  - 마지막 Admin은 역할 변경·탈퇴 불가
```

### 🟠 Manager (매니저)

```
포함 권한:
  ✅ 모든 동영상 생성·편집·삭제
  ✅ 모든 라이브 스트림 관리
  ✅ 플레이어 설정 변경
  ✅ API 키 발급 (자신이 소유한 키만 삭제)
  ✅ 웹훅 관리
  ✅ 통계 및 CSV 내보내기

제외 권한:
  ✕ 사용자 관리 (초대·역할·제거)
  ✕ 조직 정보 수정
  ✕ 플랜 변경 및 청구 관리
  ✕ 다른 사용자 API 키 삭제
```

### 🟢 Developer (개발자)

```
포함 권한:
  ✅ 동영상 업로드·조회·편집 (메타데이터)
  ✅ 라이브 스튜디오 조회
  ✅ 통계 조회 (내보내기 불가)
  ✅ API 사용 (발급된 키로)

제외 권한:
  ✕ 동영상 삭제
  ✕ 재생 정책 변경
  ✕ 라이브 스트림 생성·삭제·종료
  ✕ 플레이어 설정 변경
  ✕ API 키 발급·삭제
  ✕ 웹훅 관리
  ✕ 사용자·조직·청구 관리
```

### ⚪ Viewer (조회 전용)

```
포함 권한:
  ✅ 동영상 목록·상세 조회
  ✅ 통계 조회
  ✅ 라이브 스튜디오 조회

제외 권한:
  ✕ 모든 생성·수정·삭제 작업
  ✕ CSV 내보내기
  ✕ 설정·API·청구 접근
```

## 6. API 키 역할 범위 (Key Scopes)

API 키도 역할 개념을 적용합니다:

| 스코프 | 허용 작업 |
|--------|---------|
| `read` | GET 요청 전체 (조회 전용) |
| `write` | Read + 동영상·라이브 생성·수정 |
| `admin` | Write + 설정·사용자·청구 관리 |

```
POST /api/v1/api-keys
{
  "name": "CI/CD 파이프라인",
  "scope": "write",
  "expires_at": "2025-01-01T00:00:00Z"   // null이면 만료 없음
}
```
