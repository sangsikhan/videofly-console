# 페이지: 라이브 스튜디오 (Live Studio)

**Route:** `/live/:id/studio`  
**접근 권한:** Write 권한 이상

---

## 1. 페이지 목적

라이브 방송 진행 중 실시간 모니터링, 방송 상태 제어, 시청자 현황 확인을 위한 운영 콘솔.  
방송 담당자가 방송 중 항시 열어두는 **라이브 오퍼레이션 화면**.

---

```
│                           │  입력 신호 모니터             │
```

## 3. 구성 요소 상세

### 3.1 라이브 미리보기 플레이어

- Mux Player로 현재 방송을 실시간 미리보기
- 지연 시간: 약 3~5초 (표준 HLS)
- 음소거 상태 기본 (모니터링 목적)
- 재생 실패 시: "신호를 기다리는 중..." 메시지

### 3.2 방송 상태 지표 (실시간, 5초 갱신)

| 지표 | 표시 방식 | 경보 조건 |
|------|----------|----------|
| 연결 상태 | 🟢/🟡/🔴 | `disconnected` 시 빨강 |
| 비트레이트 | kbps 수치 | 설정 비트레이트의 70% 이하 시 경고 |
| 해상도 | WxH | - |
| FPS | N fps | 25fps 이하 시 경고 |
| 오디오 | 코덱 + kbps | 무음 감지 시 경고 |

### 3.3 비트레이트 그래프

- 최근 60초간 입력 비트레이트 타임라인
- 목표 비트레이트 점선 기준선
- 이상 구간 강조 표시

### 3.4 시청자 현황

```
현재 시청자: 342명      최고 동시 시청자: 521명
총 시청 시작: 1,203회   평균 시청 시간: 12분 30초
```

시청자 추이 라인 그래프 (최근 30분)

### 3.5 방송 제어

| 버튼 | 동작 |
|------|------|
| [방송 종료] | 확인 모달 후 스트림 강제 종료 |
| [스트림 키 재발급] | 새 키 발급 (기존 키 무효화) |
| [녹화 다운로드] | 현재까지 녹화 분 VOD 확인 |

**방송 종료 확인 모달:**
```
방송을 종료하시겠습니까?

현재 시청자 342명이 시청 중입니다.
방송 종료 시 자동으로 VOD가 생성됩니다.

[취소]  [방송 종료]
```

## 4. 연결 끊김 처리

방송 중 연결이 끊어질 경우:

```
🟡 연결이 끊어졌습니다.
재연결을 기다리는 중... (남은 시간: 45초)

인코더의 연결이 복구되면 방송이 자동으로 재개됩니다.
```

- `reconnect_window` 시간 내 재연결 성공 → 방송 자동 재개
- 시간 초과 → 스트림 종료 처리


## 6. 녹화 상태 표시

| 녹화 설정 | 표시 |
|----------|------|
| 자동 녹화 활성 중 | 🔴 녹화 중 (방송 시간과 동일) |
| 자동 녹화 비활성 | ⚪ 녹화 없음 |

| 연결 끊김 | 🔔 화면 알림 + 빨간 경보 |
