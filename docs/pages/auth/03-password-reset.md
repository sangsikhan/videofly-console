# 페이지: 비밀번호 재설정 (Password Reset)

**Routes:**
- `/forgot-password` — 이메일 입력 화면
- `/reset-password?token=xxx` — 새 비밀번호 입력 화면

---

## 1. Step 1: 이메일 입력 (/forgot-password)

```
┌────────────────────────────────────────┐
│                                        │
│  비밀번호를 잊으셨나요?                │
│                                        │
│  가입 시 사용한 이메일 주소를 입력하면 │
│  재설정 링크를 보내드립니다.           │
│                                        │
│  이메일 주소 *                         │
│  [________________________________]    │
│                                        │
│  [재설정 링크 보내기]                  │
│                                        │
│  로그인 페이지로 돌아가기 ←            │
│                                        │
└────────────────────────────────────────┘
```

### 처리 규칙

- 등록된 이메일: 재설정 링크 발송 + 안내 화면
- 미등록 이메일: **동일한 안내 화면 표시** (이메일 존재 여부 노출 방지)
- 발송 후 60초 동안 재발송 버튼 비활성화

### 발송 완료 화면

```
이메일을 확인해주세요 ✉️

hong@example.com 으로 비밀번호 재설정 링크를 보냈습니다.
링크는 1시간 동안 유효합니다.

스팸함도 확인해보세요.

[이메일 재발송]  (60초 대기 중...)

[로그인 페이지로 돌아가기]
```

---

## 2. Step 2: 새 비밀번호 입력 (/reset-password?token=xxx)

```
┌────────────────────────────────────────┐
│                                        │
│  새 비밀번호 설정                      │
│                                        │
│  새 비밀번호 *                         │
│  [________________________________]    │
│  [████████░░] 강함                     │
│                                        │
│  비밀번호 확인 *                       │
│  [________________________________]    │
│                                        │
│  [비밀번호 변경하기]                   │
│                                        │
└────────────────────────────────────────┘
```

### 토큰 검증

| 상태 | 처리 |
|------|------|
| 유효한 토큰 | 비밀번호 입력 폼 표시 |
| 만료된 토큰 | "링크가 만료되었습니다" + 재발송 안내 |
| 잘못된 토큰 | "유효하지 않은 링크입니다" + 재발송 안내 |
| 이미 사용된 토큰 | "이미 사용된 링크입니다" + 로그인 안내 |

### 만료 화면

```
링크가 만료되었습니다 ⏰

비밀번호 재설정 링크는 1시간 동안만 유효합니다.
새로운 링크를 요청해주세요.

[새 링크 요청하기]
```

---

## 3. Step 3: 변경 완료

```
비밀번호가 변경되었습니다! ✅

새 비밀번호로 로그인하세요.

[로그인 하러 가기]
```

- 변경 완료 즉시 기존 모든 세션 무효화
- 사용자에게 이메일 알림: "비밀번호가 변경되었습니다"

---

```
안녕하세요, {name}님

(링크: https://videofly.co.kr/reset-password?token=xxx)

본인이 요청하지 않으셨다면 이 이메일을 무시하세요.
계정 보안이 걱정되신다면 support@videofly.co.kr 로
문의해주세요.
```
