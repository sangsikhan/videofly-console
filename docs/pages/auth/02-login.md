# 페이지: 로그인 (Login)

**Route:** `/login`  
**접근 권한:** 비로그인 (로그인 상태에서 접근 시 `/dashboard`로 리다이렉트)

## 2. 입력 필드 명세

| 필드 | 타입 | 검증 |
|------|------|------|
| 이메일 | email | 형식 검증 |
| 비밀번호 | password | 비어 있지 않음 |

- 비밀번호 필드: 눈 아이콘으로 표시/숨김 토글
- Enter 키: 폼 제출

---

## 3. 로그인 성공 흐름

```
로그인 성공
    │
    ├── returnUrl 파라미터 있음 → 해당 URL로 이동
    │   예: /login?returnUrl=/videos/abc123
    │
    ├── 온보딩 미완료 계정 → /onboarding
    │
    └── 일반 → /dashboard
```

---

## 4. 로그인 실패 처리

### 오류 메시지 전략

보안상 이메일 존재 여부를 노출하지 않음:

```
이메일 또는 비밀번호가 올바르지 않습니다.
```

(이메일 없음 / 비밀번호 틀림을 구분하지 않음)

### 연속 실패 잠금

| 실패 횟수 | 조치 |
|----------|------|
| 1~4회 | 오류 메시지만 표시 |
| 5회 | "10분 후 다시 시도해주세요" + 타이머 |
| 10회 | 이메일로 계정 보안 알림 발송 |

```
너무 많은 로그인 시도가 감지되었습니다.
10분 후 다시 시도하거나 비밀번호를 재설정해주세요.

남은 시간: 09:32

[비밀번호 재설정]
```

[인증 이메일 재발송]
```

## 6. 소셜 로그인 흐름

```
[Google로 로그인 클릭]
        │
        ▼
[Google OAuth 팝업]
        │
        ├── Google 계정 인증 성공
        │         │
        │         ├── 기존 계정 → 대시보드 이동
        │         │
        │         └── 미가입 이메일 → 자동 가입 후 온보딩
        │
        └── 팝업 닫힘 / 취소 → 로그인 페이지 복귀
```

---

## 7. "로그인 상태 유지" 동작

| 설정 | 세션 만료 |
|------|---------|
| 체크 안 함 | 브라우저 종료 시 만료 |
| 체크함 | 30일 (Refresh Token 기반) |

Refresh Token은 HttpOnly, Secure, SameSite=Strict Cookie로 저장.

```

{
  "email": "hong@example.com",
  "password": "SecurePass123!",
  "remember_me": true
}

{
  "access_token": "eyJhbGci...",
  "token_type": "Bearer",
