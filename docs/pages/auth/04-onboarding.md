# 페이지: 온보딩 (Onboarding)

**Route:** `/onboarding`  
**접근 권한:** 로그인 (온보딩 미완료 계정에만 표시)  
**트리거:** 이메일 인증 완료 후 첫 로그인 시 자동 이동

---

## 1. 페이지 목적

신규 사용자가 VideoFly의 핵심 가치를 **5분 이내에 직접 체험**하도록 유도.  
온보딩 완료율 및 사용자 첫 성공 경험(Aha Moment)을 최대화한다.

> **Aha Moment:** "내 동영상이 실제로 재생되는 것을 확인하는 순간"

---

## 2. 전체 스텝 구성

```
Step 1/4   용도 선택 (선택형, 빠른 개인화)
Step 2/4   첫 동영상 업로드 (핵심 행동)
Step 3/4   재생 확인 (Aha Moment)
Step 4/4   다음 단계 안내 (확장 경로 제시)
```

- 각 스텝: 상단 진행률 바 + "N/4" 표시
- 모든 스텝: "나중에 하기" 링크 (→ `/dashboard`)
- 뒤로 가기: 이전 스텝으로 이동

## 4. Step 2: 첫 동영상 업로드

```
┌──────────────────────────────────────────────────┐
│  ● ●  ○  ○   2/4                                │
│                                                  │
│  첫 번째 동영상을 업로드해보세요 🎬              │
│                                                  │
│  ┌──────────────────────────────────────┐        │
│  │                                      │        │
│  │  ⬆   파일을 여기에 드래그하거나       │        │
│  │      클릭하여 선택하세요             │        │
│  │                                      │        │
│  │  MP4, MOV, AVI... · 최대 5GB        │        │
│  └──────────────────────────────────────┘        │
│                                                  │
│  또는  [URL로 가져오기]                          │
│                                                  │
│  ───────────── 샘플로 시작하기 ─────────────     │
│  [🎬 샘플 동영상 사용하기]                       │
│  (VideoFly 소개 영상 30초를 내 계정에 복사)      │
│                                                  │
│  ← 이전                나중에 하기               │
└──────────────────────────────────────────────────┘
```

### 업로드 중 상태

```
제품_소개.mp4 업로드 중...
[████████████░░░░░░] 65%   1.5GB / 2.3GB

인코딩이 완료되면 다음 단계로 이동됩니다.
```

### "샘플 동영상 사용하기" 동작

- VideoFly 소개 샘플 영상(30초)을 사용자 계정에 복사
- 별도 업로드 없이 즉시 Step 3 진행
- **온보딩 완료율 향상을 위한 마찰 제거 장치**

```

│  ● ● ● ●   4/4  🎉 온보딩 완료!                │
│                                                  │
│  VideoFly를 시작할 준비가 되었습니다.            │
│                                                  │
│  다음으로 무엇을 하시겠어요?                     │
│                                                  │
│  ┌──────────────────────────────────────────┐    │
│  │  🔑  API 키 발급하기                     │    │
│  │      내 서비스에 동영상 기능 통합         │    │
│  │                          [API 설정 →]   │    │
│  ├──────────────────────────────────────────┤    │
│  │  📡  첫 라이브 방송 시작하기             │    │
│  │      OBS 연결 → 지금 방송 시작           │    │
│  │                         [라이브 만들기→] │    │
│  ├──────────────────────────────────────────┤    │
│  │  📊  분석 확인하기                       │    │
│  │      방금 업로드한 영상의 통계 보기       │    │
│  │                            [분석 보기→] │    │
```

- 선택한 용도(Step 1)에 따라 카드 순서 재배열
  - 개발자 → API 키 발급 최상단
  - 미디어/방송 → 라이브 방송 최상단
  - 교육 플랫폼 → 동영상 관리 최상단

---

## 7. 온보딩 생략 처리

- "나중에 하기" 클릭 시 → 대시보드로 이동, 온보딩 상태 `skipped`로 저장
- 대시보드에 **온보딩 재개 배너** 표시:

```
┌──────────────────────────────────────────────────────┐
│  시작 가이드 [████░░░░] 50% 완료      [계속하기] [X] │
└──────────────────────────────────────────────────────┘
```

---

## 8. 온보딩 완료 기준

| 이벤트 | 완료로 간주 |
|--------|-----------|
| Step 4 완료 | ✅ 완전 완료 |
| Step 3까지 완료 (임베드 코드 복사) | ✅ 핵심 완료 |
| 대시보드에서 첫 동영상 업로드 완료 | ✅ 간접 완료 |
| "나중에 하기" 3회 이상 | ✅ 이후 안내 배너 숨김 |

---

## 9. 분석 이벤트

| 이벤트 | 설명 |
|--------|------|
| `onboarding_started` | 온보딩 Step 1 진입 |
| `onboarding_use_case_selected` | 용도 선택 완료 |
| `onboarding_video_uploaded` | 첫 동영상 업로드 완료 |
| `onboarding_sample_used` | 샘플 동영상 사용 |
| `onboarding_aha_moment` | 업로드 영상 재생 확인 |
| `onboarding_embed_copied` | 임베드 코드 복사 |
| `onboarding_completed` | Step 4 완료 |
| `onboarding_skipped` | 나중에 하기 클릭 |
