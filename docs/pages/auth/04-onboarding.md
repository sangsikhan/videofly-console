# 페이지: 온보딩 (Onboarding)

**Route:** `/onboarding`  
**접근 권한:** 로그인 (온보딩 미완료 계정)  
**트리거:** 이메일 인증 완료 후 최초 로그인

---

## 1. 페이지 목적

신규 사용자가 **조직 생성 → 첫 동영상 업로드 → 재생 확인(Aha Moment)** 까지  
5분 이내에 완료하도록 유도. VideoFly의 핵심 가치를 직접 체험하게 한다.

---

## 2. 전체 스텝 구성

```
Step 1/5   조직 생성
Step 2/5   플랜 선택 (Free로 즉시 시작 가능)
Step 3/5   서비스 용도 선택 (개인화)
Step 4/5   첫 동영상 업로드 (핵심 행동)
Step 5/5   재생 확인 (Aha Moment) + 다음 단계 안내
```

---

## 8. 조직 초대로 합류한 경우 (간소화 온보딩)

기존 조직에 초대 수락으로 합류한 신규 사용자는 조직 생성·플랜 선택 스텝 생략:

```
Step 1/2   서비스 용도 선택
Step 2/2   소속 조직 및 역할 확인

조직: (주)에이비씨
역할: Developer
권한: 동영상 업로드·관리, 통계 조회, API 사용

[대시보드로 이동 →]
```

---

## 9. 온보딩 생략 및 재개

- "나중에 하기" 클릭 → 대시보드 이동, 진행률 배너 표시
- 대시보드 진행률 배너:
  ```
  온보딩 [●●●○○] 3/5 완료   [계속하기 →]   [X]
  ```
