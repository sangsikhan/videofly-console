# 페이지: 회원가입 (Sign Up)

**Route:** `/signup`  
**접근 권한:** 비로그인 (로그인 상태에서 접근 시 `/dashboard`로 리다이렉트)

---

## 1. 페이지 목적

방문자를 VideoFly 계정 보유 사용자로 전환.  
**핵심 원칙:** 입력 항목 최소화, 가입 완료까지 마찰 최소화.

---

## 2. 레이아웃 구성

```
┌──────────────────────────────────────────────────────────┐
│  Navigation (로고만, 심플)                                │

│  │                        │  │                      │   │

```

- **모바일:** 폼만 전체 화면, 가치 패널 숨김

## 3. 가입 폼 (좌측)

### URL 파라미터 처리

| 파라미터 | 처리 방식 |
|---------|---------|
| `?plan=starter` | 가입 후 Starter 플랜 자동 선택 |
| `?plan=pro` | 가입 후 Pro 플랜 자동 선택 |
| `?from=pricing` | 요금제 페이지에서 유입 (분석용) |
| `?ref=docs` | 문서에서 유입 (분석용) |

### 폼 구성

```
VideoFly 시작하기
신용카드 불필요 · Free 플랜 영구 무료

──────────────────────────────────
[G] Google로 계속하기
──────────────────────────────────
           또는
──────────────────────────────────

이름 *
[_______________________]

이메일 주소 *
[_______________________]
  ✕ 이미 사용 중인 이메일입니다   (실시간 중복 확인)

비밀번호 *
[_______________________] [👁]
  [████░░░░] 보통 강도

  ✅ 8자 이상
  ✅ 대문자 포함
  ✕  특수문자 포함

☑ (필수) 이용약관 및 개인정보처리방침에 동의합니다
□ (선택) 제품 업데이트 및 마케팅 이메일 수신에 동의합니다

[무료 계정 만들기]

이미 계정이 있으신가요? 로그인 →
```

### 입력 필드 명세

| 필드 | 타입 | 검증 규칙 |
|------|------|---------|
| 이름 | text | 2~50자, 필수 |
| 이메일 | email | RFC 5322 형식, 중복 확인, 필수 |
| 비밀번호 | password | 8자 이상, 필수 |
| 이용약관 동의 | checkbox | 필수 체크 |

### 비밀번호 강도 기준

| 강도 | 조건 | 색상 |
|------|------|------|
| 약함 | 8자 미만 또는 숫자만 | 빨강 |
| 보통 | 8자 이상 + 영문 | 주황 |
| 강함 | 8자 이상 + 영문 + 숫자 + 특수문자 | 초록 |

### CTA 버튼 상태

| 상태 | 텍스트 |
|------|--------|
| 기본 | "무료 계정 만들기" |
| 로딩 중 | "⏳ 계정 생성 중..." (비활성) |
| 오류 | 인라인 에러 표시, 버튼 재활성화 |

## 5. 가입 완료 후 흐름

```
[가입 버튼 클릭]
        │
        ▼
[서버: 계정 생성 + 이메일 발송]
        │
        ▼
[이메일 인증 안내 화면]
        │
        ├── 이메일의 링크 클릭
        │         │
        │         ▼
        │   [이메일 인증 완료]
        │         │
        │         ▼
        │   [온보딩 /onboarding]
        │
        └── 30분 후 미인증 → 재발송 버튼 표시
```

## 7. Google OAuth 흐름

```
[Google로 계속하기 클릭]
        │
        ▼
[Google 계정 선택 팝업]
        │
        ▼
[VideoFly 콜백: /auth/google/callback]
        │
        ├── 신규 사용자 → 이름 확인 화면 → 약관 동의 → 온보딩
        └── 기존 사용자 → 대시보드
```

Google OAuth 이점: 이메일 인증 과정 생략 (Google이 인증 주체).

---

## 8. 에러 처리

| 에러 | 표시 방식 |
|------|---------|
| 이메일 중복 | 이메일 필드 아래 인라인 오류 + "로그인하기" 링크 |
| 네트워크 오류 | 버튼 위 에러 배너 + 재시도 |
| OAuth 실패 | 에러 메시지 + "이메일로 가입하기" 대안 제시 |
| 서버 오류(5xx) | "잠시 후 다시 시도해주세요" |

---

## 9. 분석 이벤트 (Analytics)

| 이벤트 | 트리거 |
|--------|--------|
| `signup_page_view` | 페이지 로드 시 |
| `signup_method_selected` | Google 또는 이메일 선택 |
| `signup_form_submitted` | 가입 버튼 클릭 |
| `signup_completed` | 계정 생성 성공 |
| `signup_email_verified` | 이메일 인증 완료 |
