# 페이지: 동영상 목록 (Video List)

**Route:** `/videos`  
**접근 권한:** Read 권한 이상

---

## 1. 페이지 목적

계정의 모든 동영상 에셋을 목록으로 탐색·관리하는 페이지.  
필터, 정렬, 검색 기능을 통해 원하는 동영상을 빠르게 찾고 관리한다.

---

## 2. 레이아웃 구성

```
┌──────────────────────────────────────────────────────────┐
│  헤더: "동영상 목록"                    [+ 동영상 업로드]  │
├──────────────────────────────────────────────────────────┤
│  검색: 🔍 [제목 또는 태그 검색...]                        │
│  필터: [상태 ▼] [날짜 ▼] [재생정책 ▼]  정렬: [날짜순 ▼]  │
│  뷰 전환: [≡ 목록] [⊞ 그리드]                            │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  [동영상 목록 테이블 또는 그리드]                         │
│                                                          │
├──────────────────────────────────────────────────────────┤
│  페이지네이션: < 1 2 3 ... 10 >   총 198개               │
└──────────────────────────────────────────────────────────┘
```

---

## 3. 목록 뷰 (테이블)

### 컬럼 정의

| 컬럼 | 설명 | 정렬 가능 |
|------|------|----------|
| □ (체크박스) | 일괄 작업용 선택 | - |
| 썸네일 | 60×34px 미리보기 이미지 | - |
| 제목 | 동영상 제목 (클릭 → 상세 이동) | ○ |
| 상태 | 인코딩 상태 배지 | ○ |
| 재생 정책 | 공개/서명 배지 | - |
| 재생시간 | hh:mm:ss | - |
| 업로드 일시 | YYYY-MM-DD HH:mm | ○ |
| 재생수 | N회 | ○ |
| 작업 | ⋮ 메뉴 (수정/삭제/임베드) | - |

### 상태 배지 색상

| 상태 | 배지 색상 | 설명 |
|------|----------|------|
| `ready` | 초록 | 재생 가능 |
| `preparing` | 파랑 | 인코딩 중 |
| `waiting` | 회색 | 업로드 대기 |
| `errored` | 빨강 | 오류 발생 |

---

## 4. 그리드 뷰

- 3열 그리드 (데스크톱), 2열 (태블릿), 1열 (모바일)
- 각 카드: 썸네일 (16:9) + 제목 + 상태 배지 + 재생시간

---

## 5. 필터 및 검색

### 검색

- 제목 또는 태그 기준 실시간 검색 (debounce 300ms)
- 검색어 하이라이팅

### 상태 필터

| 옵션 | 표시 데이터 |
|------|-----------|
| 전체 | 모든 에셋 |
| 준비 완료 | `ready` |
| 인코딩 중 | `preparing`, `waiting` |
| 오류 | `errored` |

### 날짜 필터

| 옵션 | 기간 |
|------|------|
| 오늘 | 오늘 0시 ~ 현재 |
| 최근 7일 | 7일 전 ~ 현재 |
| 최근 30일 | 30일 전 ~ 현재 |
| 기간 직접 입력 | 날짜 범위 선택 |

### 재생 정책 필터

- 공개 / 서명 필요

### 정렬

| 정렬 기준 | 방향 |
|----------|------|
| 업로드 날짜 | 최신순 (기본) / 오래된순 |
| 제목 | 가나다순 / 역순 |
| 재생수 | 많은순 / 적은순 |

---

## 6. 일괄 작업 (Bulk Actions)

1개 이상 체크박스 선택 시 일괄 작업 바 표시:

```
선택된 항목: 3개       [태그 추가] [재생정책 변경] [삭제]
```

| 작업 | 설명 |
|------|------|
| 태그 추가 | 선택된 동영상에 태그 일괄 적용 |
| 재생정책 변경 | public ↔ signed 일괄 전환 |
| 삭제 | 삭제 확인 모달 후 일괄 삭제 |

---

## 7. 빈 상태 (Empty State)

동영상이 없을 때:

```
     🎬
  첫 번째 동영상을 업로드하세요

  [동영상 업로드] 버튼
```

검색/필터 결과 없을 때:

```
     🔍
  검색 결과가 없습니다.
  다른 검색어나 필터를 사용해보세요.
```

---

## 8. 개별 항목 컨텍스트 메뉴 (⋮)

| 메뉴 항목 | 동작 |
|----------|------|
| 상세 보기 | `/videos/{id}` 이동 |
| 임베드 코드 복사 | 모달로 iframe 코드 표시 |
| 재생 정책 변경 | 즉시 토글 |
| 다운로드 URL 복사 | MP4 URL 클립보드 복사 (허용된 경우) |
| 삭제 | 확인 모달 후 삭제 |
